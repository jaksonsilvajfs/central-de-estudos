# Central de Estudos

Monitor de estudos para **Instituições Judiciais e Ética** (Direito — 1º período), publicado como PWA.

- Instale pelo navegador ("Adicionar à tela inicial" / "Instalar app").
- Funciona offline: os dados ficam salvos no próprio aparelho (localStorage).
- Os recursos com IA (guias, perguntas, correções, orientações) só funcionam quando a página é aberta dentro do Claude.
